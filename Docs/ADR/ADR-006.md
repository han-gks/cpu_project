# [ADR-006] CSR 명령어 연산·갱신 타이밍 및 직렬화 제어

- **작성일자:** 2026-10-30
- **작성자 / 리뷰어:** 한대규/장병옥, 정현재
- **상태:** 승인됨 (Accepted)
- **영향 범위:** CSR 읽기·연산·쓰기 단계 배치, 파이프라인 단계 레지스터, CSR 직렬화 정지(Stall) 및 플러시 제어

---

### 1. 배경 및 문제 정의

CSR 명령어(`CSRRW`, `CSRRS`, `CSRRC`, `CSRRWI`, `CSRRSI`, `CSRRCI`)는 단일 명령어 안에서 **기존 CSR 값을 읽어 목적지 일반 레지스터(`rd`)에 기록**함과 동시에 **새로운 값을 계산해 해당 CSR에 덮어쓰기(WRITE)·비트 설정(SET)·비트 해제(CLEAR)**하는 읽기-수정-쓰기(Read-Modify-Write) 동작을 수행한다.

5단계 파이프라인(ADR-001)과 EX 단계 분기 판정(ADR-002) 구조에서 CSR 상태를 어느 단계에서 변경할지에 따라, 투기적(Speculative) 실행 취소 시 복구 비용과 연속 CSR 접근 시 의존성 제어 복잡도가 크게 달라진다.

### 2. 요구사항 및 제약조건

- 잘못된 분기 경로에 있거나 앞선 명령어의 예외로 취소되어야 할 젊은 CSR 명령어가 건축적 상태(CSR)를 오염시키지 않아야 한다.
- `CSRRW/CSRRWI`에서 `rd=x0`이면 CSR 읽기를 생략하고, `CSRRS/CSRRC`(`rs1=x0`) 및 `CSRRSI/CSRRCI`(`zimm=0`)이면 CSR 쓰기를 생략해야 한다.
- `mstatus.MIE`나 `mie` 변경 등 제어 상태를 바꾸는 CSR 명령어 이후의 명령어는 갱신된 CSR 상태를 기준으로 실행되어야 한다.
- 아래 사이클 수, 파이프라인 FF 증가량, CPI 영향은 5단계 파이프라인 기준의 **설계 전 정량 분석치**다.

### 3. 대안 비교

| 비교 항목 | 대안 A: EX 단계 읽기·연산·쓰기 | 대안 B: EX 읽기·연산, WB 단계 쓰기 | **대안 C: WB 단계 일괄 읽기·연산·쓰기 + 파이프라인 직렬화 (선택)** |
| :--- | :--- | :--- | :--- |
| **상태 변경 시점** | EX 단계 | WB 단계 | **WB 단계** |
| **추가 파이프라인 FF*** | 약 55 FF (ID/EX에만 전달) | 약 195 FF (계산된 신·구 CSR 값 64b를 EX/MEM, MEM/WB에 전달) | **약 150 FF** (CSR 주소 12b·피연산자 32b·제어 6b를 WB까지 전달) |
| **취소/복구(Rollback) 비용** | EX 이후 예외 발생 시 CSR 복구용 Shadow FF(+224 FF) 필요 | WB 전 취소 시 쓰기만 막으면 됨(0 FF) | **WB 전 취소 시 쓰기만 막으면 됨(0 FF)** |
| **CSR 전용 포워딩 MUX** | 불필요 | 연속 CSR 접근을 위해 32b × 2단 CSR 우회 MUX 필요 | **불필요** (직렬화 보류로 WB 완료 후 후속 명령 진행) |
| **CSR 명령어당 정지 페널티** | 0사이클 | 0~2사이클 (의존성에 따름) | **3사이클 버블 삽입** (CSR이 EX·MEM·WB에 있는 동안 IF/ID 보류) |
| **전체 성능(CPI) 영향**** | +0.00 CPI | +0.01 CPI 미만 | **+0.03 CPI 미만** (CSR 실행 비중 1% 미만 기준) |

\* **파이프라인 FF 계산:** 대안 C는 ID/EX, EX/MEM, MEM/WB 3개 경계에 `CSR 주소(12b) + 피연산자(32b) + 제어 신호(Op 2b, En 1b, WrEn 1b, RdEn 1b, ImmSel 1b = 6b) ≈ 50 FF/단계 × 3단계 = 약 150 FF`가 필요하다(실제 RTL에서는 즉시값 `Imm` 32b 레지스터도 EX/MEM, MEM/WB로 함께 전달하여 하위 5비트 `rMEM_WB_Imm[4:0]`을 `zimm`으로 사용). 반면 대안 B는 EX에서 읽은 기존 CSR 값(32b, `rd` 기록용)과 새로 계산한 CSR 값(32b, CSR 기록용)을 모두 WB까지 운반해야 하므로 EX/MEM과 MEM/WB에서 단계당 32b가 더 든다.

\*\* **CPI 영향 추정:** 일반 애플리케이션 및 RTOS 워크로드에서 CSR 명령어는 트랩 진입/복귀 및 문맥 전환 시에만 나타나 전체 동적 명령어의 0.5%~1.0% 미만이다. 따라서 CSR 명령어당 3사이클의 직렬화 버블이 발생하더라도 평균 CPI 증가량은 `0.01 × 3 = 0.03 CPI` 이하로 미미하다.

#### 타이밍 예시

표기: `CSR`은 CSR 명령어, `I1`은 직후 명령어, `×(버블)`은 직렬화 대기 동안 삽입된 무효 슬롯이다.

##### 대안 B: EX 연산·WB 쓰기 (연속 CSR 접근 시 우회 필요)

| 명령어 \ 사이클 | C1 | C2 | C3 | C4 | C5 | C6 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `csrrw x5, mstatus, x1` | IF | ID | EX (읽기·계산) | MEM | WB (CSR 쓰기) | |
| `csrrs x6, mstatus, x2` | | IF | ID | EX (**우회 없으면 구버전 읽음**) | MEM | WB |

##### 대안 C: WB 일괄 처리 + 파이프라인 직렬화 (선택)

| 명령어 \ 사이클 | C1 | C2 | C3 | C4 | C5 | C6 | C7 | C8 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `csrrw x5, mstatus, x1` | IF | ID | EX (`rs1` 확보) | MEM | WB (CSR 읽기·연산·쓰기) | | | |
| 직렬화 버블 슬롯 | | IF (`I1`) | × (버블 1) | × (버블 2) | × (버블 3) | | | |
| `I1` (후속 명령어) | | | PC 정지 | PC 정지 | PC 정지 | IF (`I1`) | ID | EX |

`CSR` 명령어가 ID/EX, EX/MEM, MEM/WB에 머무는 3사이클(C3~C5) 동안 PC를 정지하고 IF/ID를 플러시(버블 삽입)한다. C5 종료 시점에 CSR과 목적 레지스터 `x5`가 모두 갱신되므로, C6에 인출되는 후속 명령어 `I1`은 별도의 CSR 포워딩 경로 없이도 항상 최신 CSR 상태와 최신 `x5` 값을 관측한다.

### 4. 결정 및 근거

- **선택:** 대안 C — CSR 읽기·연산·쓰기를 모두 WB 단계에서 일괄 수행하고, 파이프라인(ID/EX ~ MEM/WB)에 유효한 CSR 명령어가 존재하는 3사이클 동안 후속 명령어 인출을 보류(PC 정지 + IF/ID 버블)한다.
- **근거:**
  1. **설계 단순성과 면적 절감:** CSR 상태 변경을 WB로 단일화하여 잘못된 분기나 예외 시 복구용 Shadow 레지스터(224 FF)를 제거하고, 3사이클 직렬화를 통해 CSR 전용 우회 MUX(64b+)와 복잡한 CSR 주소 비교기를 생략할 수 있다.
  2. **부작용 원천 차단:** EX에서 taken 분기가 판정되면(ADR-002) IF/ID와 ID/EX의 젊은 CSR 명령어는 WB에 도달하기 전에 플러시되므로 잘못된 CSR 쓰기가 절대 발생하지 않는다.
  3. **낮은 성능 손실:** CSR 명령어당 3사이클이 소비되지만 실행 빈도가 1% 미만이므로 전체 처리량(CPI) 손실은 3% 이내로 충분히 감수 가능하다.
- **감수 사항:** CSR 명령어 실행 시마다 3사이클의 파이프라인 직렬화 버블이 발생하며, CSR 제어 및 피연산자 전달을 위해 약 150 FF의 파이프라인 레지스터가 추가된다.

### 5. 결과 및 후속 결정

- **CSR의 일반 레지스터(`rs1`) 소비 경로:** CSR 명령어가 앞선 ALU/Load 결과를 `rs1`으로 사용할 때의 포워딩 및 정지 규칙 정의 (ADR-007)
- **전용 블록 분리:** 일반 ALU 경로와 섞지 않고 WB 단계에 전용 CSR 연산기와 CSR 레지스터 파일을 배치
- **트랩과의 결합:** WB 단계 소프트웨어 CSR 쓰기와 하드웨어 트랩 갱신 간 우선순위 정의 (ADR-008)
